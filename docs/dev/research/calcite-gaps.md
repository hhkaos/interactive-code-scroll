# Calcite gaps

Needs that Calcite Design System (5.1.2) could not cover through its public API (props, slots, tokens), with the workaround we use and what we would ask the Calcite team for. Project rule (`PROJECT.md`, Coding style): style Calcite only through tokens, props and slots, never shadow internals; where that is not enough we build our own element, and record it here.

Use this list when reviewing with Calcite experts (see the `calcite-shell` item in `TODO.md`) and when upgrading Calcite: a gap closed upstream lets us drop a workaround.

| Need | What Calcite offers | Gap | Our workaround | Ask |
|---|---|---|---|---|
| Header title that shrinks with an ellipsis on phones | `calcite-navigation-logo` (`heading`, `description`, `thumbnail`); its shadow heading has `text-overflow: ellipsis` | The navigation's slot wrapper is a flex box without `min-width: 0`, so the logo never shrinks: a long title pushes the header actions off screen and the ellipsis never shows | Tutorial pages use our own `div.page-title` (img + `h1`) in the `logo` slot, same geometry as the logo at scale m; `startHeaderTitle()` in `client/layout.ts` caps its width to the room the other slots leave (`titleRoom`) | `min-width: 0` on the slot wrappers (or a `shrink` behavior for the logo slot) so slotted content can ellipsize |
| A control on the title's second line (sibling tutorial menu on phones) | `description`: plain text only | No slot for the second line, and no way to align or space it: with `description` the block sat low in the 64 px bar (title 14–38 px, description 49–65 px) with an 11 px gap | Own title block: the `calcite-dropdown` itself moves under the `h1` on phones (transparent, scale s), so the second line is a real button | A slot (e.g. `description` slot) and centered vertical alignment of heading + description |
| Header type size and line height per breakpoint | `scale` (s/m/l) | Typography and line-height are internal variables (`--calcite-internal-navigation-logo-*`); only colors are public tokens | Own title block styled with Calcite font tokens (`--calcite-font-size-xl` desktop, `-md` phones) | Public tokens for heading/description size and line height |
| Header that adapts to narrow screens | `calcite-navigation` slots (`logo`, `content-start`, `content-end`, `navigation-action`) | No responsive behavior: no overflow menu, no way to collapse slots | Phone-only CSS hides desktop-only actions (Present, copy, download) and `client/layout.ts` moves the sibling menu | An overflow pattern or documented responsive guidance for `calcite-navigation` |
| A floating element inside the header (title popover) | `calcite-popover` with `reference-element` | `calcite-navigation` has no default slot: an unslotted child is never rendered | The popover lives after `</calcite-navigation>` | Document it, or render unslotted children |
| A heading inside a dropdown menu (full title above the sibling list) | `calcite-dropdown-group` `group-title` | A hidden or empty group still draws the separator above the next group | `client/layout.ts` inserts the full-title group only while it is needed | Skip the separator next to hidden groups, or a non-interactive menu header |
| Opening a dropdown from another element (tapping the title opens the sibling menu) | `open` property | The dropdown closes on any outside pointerdown/click, including the click that opened it programmatically | Open it in the next animation frame, after that click has gone through | An option to ignore a given element as "outside", or a public `toggle()` that accounts for it |
| Numeric badge on an action (ZIP file count) | `calcite-action` `indicator` (a dot) | No number; and `indicator` throws when its t9n strings are not loaded (offline), collapsing the action | Our own badge (`.zip-action[data-count]::after`) | A numeric badge, and `indicator` that renders without t9n |
| No focus ring after a mouse click on a button | `:focus-visible` behavior | `calcite-button` delegates focus to its inner button and never matches `:focus-visible` on the host | Mark pointer focus from JS (`data-pointer-focus`) and clear `--calcite-color-focus` only then (`client/family.ts`) | Ring only for keyboard focus by default |
| Tooltips on touch screens | `calcite-tooltip` (hover/focus) | After a tap the tooltip stays open (no hover end on touch) | Pending (`TODO.md`, phone layout follow-ups) | Touch-aware tooltip behavior |
| Page layout with percentage splitters and nested panels | `calcite-shell`, `calcite-shell-panel` (`resizable`, px widths) | No persistent percentage width, edge panels only, scroll container inside shadow DOM (the step engine observes it) | Own CSS grid (`PROJECT.md`, Page layout) | See the `calcite-shell` review item in `TODO.md` |
| Two-line (wrapping) titles in the header | — | The logo heading is `nowrap` in shadow DOM | Not needed yet: our own title block could wrap if a UX review asks for it | — |
| Selected carousel item after creation | `calcite-carousel-item` `selected` at creation | Changing `selected` later is ignored; no select/next method | Re-create the carousel from its template on each change (`client/steps.ts`) | A public method or a reactive `selected` |
| Multiple-selection chips without a checkbox | `calcite-chip` `selection-mode="multiple"` | Always draws a checkbox | Plain `<button aria-pressed>` pills for series tag toggles | A prop to hide the checkbox |

Details and repro notes for most rows: the Known issues table in `docs/dev/PROJECT.md`.
