<Intro>

## What this playground is for

A local tutorial that grows with each step of the multi-SDK plan (`docs/research/arcgis-multi-sdk-plan.md`). Use it to try new framework features by hand. It is not covered by E2E tests; framework regressions are guarded by `examples/framework-fixture`.

> Run it with `pnpm playground` from the repository root.

</Intro>

## Python: configure the request

The access token field below updates every file that marks the same `@var`: Python, Kotlin and C#.

<VarField name="accessToken" label="Access token" secret />

The Python file uses the VS Code folding style `# region` / `# endregion`, recognized only in `.py` files.

</Step>

<Step id="curl" file="geocode.sh" region="request">

## cURL: the same request

Shell strings escape differently: try an access token containing `"`, `$` or a backtick, then download the ZIP. Python, Kotlin and C# get backslash escapes, the shell script escapes `$` and backticks too, and `.http` values are inserted as is.

</Step>

<Step id="request" file="python/geocode.py" region="request" output="geocode.json" request="geocode">

## Python: send the request

`requests.get` calls `findAddressCandidates` with the address as `singleLine`. The Result pane shows a captured response from `output/geocode.json`; the next steps keep it until another step has an output.

**Run request** sends `requests/geocode.http` from the browser with the access token above (`.http` file variables such as `@accessToken` take the field's value). `requests/` is the runner's source only: it gets no code tab but is included in the ZIP.

</Step>
